# CertificaAI

Plataforma de certificação de conhecimentos (MVP), com frontend no GitHub Pages e dados/autenticação no Supabase.

**Estado:** base inicial em desenvolvimento. Provas, correção e certificados não estão disponíveis ainda.

Repositório: https://github.com/chagasguilherme7-alt/certificaai

Supabase: https://supabase.com/dashboard/project/vnktbikulnjazhfpmbdu

Acesse Settings > Pages > Source: GitHub Actions para configurar publicação, após o envio do workflow.
